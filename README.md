# .github

Default issue forms and pull request template for every pintoolx repository that does not define its own.

- `ISSUE_TEMPLATE/task.yml`: a task, written so anyone or any agent can pick it up (context, work, done criteria).
- `ISSUE_TEMPLATE/bug.yml`: something broken on a site, the admin or a tool.
- `PULL_REQUEST_TEMPLATE.md`: what, why, how it was verified, deploy impact, and a secrets check.

This repository is public because GitHub only applies organization defaults from a public `.github` repository. Do not put anything internal here.
